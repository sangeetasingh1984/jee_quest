JEE QUEST — starter app

WHAT WORKS
- XP and levels
- Daily mission checklist
- Chapter checklist for Physics, Chemistry and Maths
- Milestone tracker
- Study-time log
- Mock score history and simple improvement insights
- Add friends and compare XP on this device
- Export/import JSON backup
- PWA files for home-screen installation when hosted on HTTPS

IMPORTANT LIMITS
- Your data is saved in this browser on this device. Clear browser data or switch browsers and it may be lost; export backups regularly.
- Friends do NOT sync across different phones in this version. Real friend invites, accounts, shared leaderboard and notifications require a backend and authentication.
- Daily recommendations use the information you enter; the app does not automatically read coaching apps, question papers, or JEE results.
- The starter chapter list is a broad checklist, not a guaranteed exact current official syllabus. Check the current NTA/JEE Main syllabus.

HOW TO GET IT ON YOUR ANDROID HOME SCREEN
1. Upload the contents of this folder to an HTTPS static host (for example, GitHub Pages).
2. Open the published website in Chrome on Android.
3. Tap ⋮ > Install app (or Add to Home screen) and confirm.
4. Open JEE QUEST from its new icon.
The app cannot be installed as a true PWA by opening index.html directly from a file manager; it needs to be served over HTTPS (or localhost for development).

FILES
- index.html: app
- manifest.json: install metadata
- sw.js: offline cache
- icon.svg: app icon
